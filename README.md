## 🎯 Проблема бизнеса в регионе (г. Тараз и Жамбылская область)

В Таразе и районах области работают свыше 15 000 продуктовых магазинов «у дома», аптек, мини-маркетов и точек общепита:
1. **Ручная рутина с бумагой:** Товар еженедельно принимается от 20–40 поставщиков (ТОО «Родина», «Цесна», «Шедевр», «Куликовский» и др.) на мятых чеках или накладных. Ручной ввод в тетрадь или 1С занимает от 15 до 20 часов в неделю.
2. **Скрытый рост цен поставщиков («Утечка маржи»):** Поставщик поднимает оптовую цену на 8–15%, предупреждая мелким шрифтом на накладной. Товаровед или продавец не замечает этого и продолжает продавать товар по старой розничной цене. Магазин неделями торгует в ноль или в минус.
3. **Языковой и технический барьер:** Традиционные ERP (1С, SAP) сложны, дороги и требуют компьютера. Приемщикам в магазине нужен интерфейс прямо в **Telegram на родном казахском или русском языке**, который сам распознает голос и фото, а данные разносит в существующие сервисы учета.

## 💡 Решение Sanau.AI

Мультимодальная экосистема (**Telegram Bot + Telegram Mini App + FastAPI Backend + Integration Hub**), которая автоматизирует приемку товаров за секунды:

1. 📸 **Распознавание фото накладных:** Нейросеть `GPT-4o-mini Vision` извлекает номенклатуру, объемы, единицы измерения и закупочные цены даже со смятых или рукописных чеков.
2. 🎙️ **Голосовая приемка на казахском и русском языках:** Приемщик на складе нажимает микрофон в Telegram и надиктовывает приход (например: _«20 сүт Родина 440 теңгеден келді, 10 қап ұн Цесна 760 теңге»_). Модели `Whisper-1` + локальный NLP-парсер мгновенно формируют электронную накладную.
3. ✍️ **Умный текстовый ввод:** Прием текста поставщика в произвольном формате без обязательных шаблонов.
4. 🚨 **«Радар маржи» (Price Spike Radar):**
   - Автоматически сверяет цену каждой позиции с историей закупа конкретного магазина;
   - Мгновенно подсвечивает скачок цены (например: `+12.8%`);
   - Рассчитывает точный риск кассового убытка магазина в тенге;
   - Автоматически рассчитывает **новую рекомендованную цену розницы**, защищая целевую маржу бизнеса (по умолчанию 25%).
5. 🏬 **Персонализация магазина:** Владелец в 1 клик настраивает имя магазина (например, *«Магазин Береке»*, *«Супермаркет Тараз»*), город, должность и целевой процент наценки.
6. 🗑️ **Полный контроль каталога:** Возможность очистить старые тестовые данные (`/clear` в боте или кнопка в приложении), удалять отдельные товары по одному (🗑️) или мгновенно вернуть 12 эталонных товаров Тараза (`/reset`).

### 📊 1. Интеграция с Google Таблицами (Google Sheets)

Sanau.AI позволяет автоматически вносить каждую накладную новой строкой в вашу Google Таблицу онлайн.

#### Способ А: Через бесплатный Google Apps Script (Рекомендуется, 2 минуты)
В репозитории подготовлен готовый скрипт: [`integrations/google_sheets_apps_script.js`](integrations/google_sheets_apps_script.js).

1. Создайте таблицу на [sheets.google.com](https://sheets.google.com).
2. В верхнем меню выберите **Расширения (Extensions) ➔ Apps Script**.
3. Вставьте код из файла [`integrations/google_sheets_apps_script.js`](integrations/google_sheets_apps_script.js).
4. Нажмите **Развернуть (Deploy) ➔ Новое развертывание (New deployment)**.
5. Выберите тип **Веб-приложение (Web app)**:
   - *Выполнять от имени*: **Я (ваш Google аккаунт)**
   - *У кого есть доступ*: **Все (Anyone)**
6. Нажмите **Развернуть**, скопируйте полученный **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`).
7. Откройте Sanau.AI Mini App ➔ вкладка **«Сервисы»** ➔ **«Настроить»** ➔ вставьте ссылку в поле **Google Sheets (Webhook URL)** ➔ **«Сохранить и привязать»**.
8. Нажмите кнопку **«Тест»** — в таблице мгновенно появится подтверждающая запись!

#### Способ Б: Через No-Code сервисы (SheetDB, Make, Zapier, n8n)
- **SheetDB.io**: Превращает любую Google Таблицу в REST API. Скопируйте ссылку API в поле *Google Sheets Webhook URL*.
- **Make / Zapier / n8n**: Создайте триггер `Custom Webhook`, скопируйте URL в настройки Sanau.AI, а следующим шагом выберите модуль `Google Sheets: Add Row`.

### 🏢 2. Интеграция с 1С:Предприятие, МойСклад и ERP

#### Способ А: Онлайн-синхронизация по REST API Webhook
1. В настройках Mini App (вкладка **«Сервисы»**) в поле **1C / ERP Webhook URL** вставьте URL эндпоинта вашей 1С или шлюза.
2. При подтверждении накладной Sanau.AI отправляет структурированный JSON-пакет стандарта `ПриходнаяНакладная`:
   - Пример реального payload: [`integrations/1c_erp_webhook_sample.json`](integrations/1c_erp_webhook_sample.json).
   - Включает: номер накладной, поставщика, список позиций, старые и новые цены закупа, рассчитанную розничную цену и флаг подорожания.
3. **Тестирование вебхука:**  
   Для быстрой проверки можно вставить эндпоинт с [webhook.site](https://webhook.site), чтобы увидеть структуру отправляемого JSON-запроса в реальном времени.

#### Способ Б: Файловый обмен в 1 клик
Во вкладке **«Сервисы»** доступны готовые выгрузки:
- **1С 8.3 XML (CommerceML 2.0):** Универсальный формат обмена для типовых конфигураций «1С:Розница для Казахстана» и «1С:Управление торговлей».
- **Excel (.xlsx):** Детализированный отчет с подсчетом рисков потерь маржи.
- **Kaspi Магазин (XML/CSV фид):** Готовый прайс-лист для автоматического обновления цен в личном кабинете Kaspi Pay.

### ✈️ 3. Telegram-оповещения руководству (Telegram Alerts)

Когда Радар маржи фиксирует рост закупочной цены:
1. Узнайте свой цифровой ID Telegram (например, у бота `@userinfobot`).
2. В Mini App во вкладке **«Сервисы» ➔ «Настроить»** укажите его в поле **Telegram Chat ID**.
3. При любой подозрительной накладной бот немедленно пришлет алерт:
   > 🚨 **ВНИМАНИЕ: Скрытый рост цен!**  
   > Поставщик: *ТОО «Родина»*  
   > Товар: *Молоко «Родина» 3.2% 1л*  
   > Закуп вырос: **390 ₸ ➔ 440 ₸ (+12.8%)**  
   > 💡 Рекомендуемая розница для сохранения маржи 25%: **570 ₸**

### 💾 4. Реляционная база данных (SQL)

- Все операции логируются в локальной SQLite базе (поддерживается подключение к PostgreSQL через `DATABASE_URL`).
- Таблицы: `products`, `suppliers`, `invoices`, `invoice_items`, `sync_logs`, `app_settings`.
- Каждое изменение отпускной цены фиксируется в журнале с отметкой даты и времени.

## 🛠️ Стек технологий

- **Backend & Core:** Python 3.9+, FastAPI, Uvicorn, SQLite3, Pydantic v2, Requests, Httpx, OpenPyXL.
- **AI & NLP:**
  - `OpenAI GPT-4o-mini` (Vision & JSON Schema structured extraction);
  - `OpenAI Whisper-1` (казахская и русская транскрипция аудио);
  - Локальный мультиязычный NLP-регулярный парсер (офлайн-обработка без внешних API).
- **Frontend / Mini App:** HTML5, Tailwind CSS, Lucide Icons, Telegram Web App SDK.
- **Интеграции:** Google Apps Script Webhook, 1C CommerceML XML 2.0, Kaspi XML Catalog, Telegram Bot API.
- **Деплой:** Docker, Railway Cloud 24/7, Cloudflare Tunnels.

## 🚀 Локальный запуск разработчика

### 1. Клонирование и виртуальное окружение:
```bash
git clone https://github.com/Almerek999/Sanau.AI.git
cd Sanau.AI

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных `.env`:
```bash
cp .env.example .env
```
Заполните `.env`:
```env
TELEGRAM_BOT_TOKEN=8663847908:AAEdXrnlynp7ollxJoa8WY47pt8YZLFJuCs
OPENAI_API_KEY=sk-proj-...
GEMINI_API_KEY=
DB_PATH=database/sanau.db
```

### 3. Запуск всего стека одной командой:
```bash
./run.sh
```
Скрипт автоматически:
- Поднимет локальный сервер на `http://localhost:8000`;
- Запустит фоновый опрос Telegram-бота;
- Если установлен `cloudflared`, создаст публичный HTTPS-туннель и привяжет кнопку в Telegram.
