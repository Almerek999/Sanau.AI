# Sanau.AI 📦🚀

> **Мультимодальный AI-товаровед, распознавание накладных и радар защиты маржи для малого и среднего бизнеса**  
> Проект разработан для регионального хакатона **Zhambyl Hub (г. Тараз)** по треку **«AI for SME & Local Business»**.

---

## 🎯 Проблема бизнеса в регионе

В Таразе и Жамбылской области свыше 15 000 магазинов «у дома», минимаркетов, аптек, складов и ресторанов:
1. **Ручная рутина с накладными:** Товар принимается от 20–40 поставщиков еженедельно на мятой бумаге, чеках или на словах. Ручной ввод в 1С или тетрадь занимает 15–20 часов в неделю.
2. **Скрытый рост цен поставщиков:** Поставщик тихо поднимает цену на 8–15%. Владелец не успевает пересчитать розницу и неделями продает товар на полке в минус или в ноль.
3. **Барьер перехода на сложные системы:** Малый бизнес не хочет внедрять тяжелые ERP. Им нужен инструмент, который живет прямо в **Telegram на телефоне** и сам передает данные в их привычные сервисы: **Google Sheets, 1С, Kaspi и базу данных**.

---

## 💡 Решение «Sanau.AI»

Мультимодальная экосистема (Telegram Bot + Telegram Mini App + FastAPI Backend), которая за секунды:
1. 📸 **Распознает бумажные накладные по фото:** нейросеть `GPT-4o-mini Vision` извлекает названия товаров, количество, единицы измерения и закупочные цены.
2. 🎙️ **Принимает живой голос на казахском и русском:** модель `Whisper-1` распознает свободную речь приемщика склада (например: _«20 сүт Родина 440 теңгеден келді...»_).
3. 🚨 **Включает «Радар маржи»:** автоматически сверяет закупочную цену с историей контракта, выявляет скрытое подорожание, рассчитывает потенциальный кассовый убыток и выдает готовую рекомендованную цену розницы.
4. 🔌 **Реально разносит данные во внешние сервисы:**
   - 📊 **Google Sheets:** онлайн-запись строк в реальную Google Таблицу через Webhook / Apps Script.
   - 🏢 **1С / ERP Webhook:** стандартизированный JSON `ПриходнаяНакладная` стандарта 1С.
   - ✈️ **Telegram Alerts:** моментальное уведомление в чат владельца о подорожании товаров.
   - 🗄️ **Локальная база данных:** ведение каталога и истории накладных в SQLite.
   - 📥 **Экспорт в 1 клик:** файлы **Excel (.xlsx)**, **1C CommerceML 2.0 (XML)** и **Kaspi Прайс-лист (CSV)**.

---

## 📱 Архитектура и интерфейсы

1. **Telegram Mini App:** Нативное мобильное веб-приложение прямо внутри Telegram (вкладки: *Приемка*, *Радар маржи*, *Каталог*, *Сервисы*).
2. **Telegram Bot ([@Sanau_AI_bot](https://t.me/Sanau_AI_bot)):** Бот для мгновенного приема фото, голосовых и отправки алертов.
3. **FastAPI REST Backend:** Высокопроизводительный сервер с фоновым воркером Telegram и Cloudflare HTTPS туннелем.
4. **Dual AI Engine:** Поддержка **OpenAI** (`gpt-4o-mini`, `whisper-1`) и **Google Gemini** (`gemini-1.5-flash`), а также встроенный офлайн-режим с каталогом Тараза для надежных выступлений на сцене.

## 🚀 Быстрый запуск

### 1. Клонирование и настройка окружения:
```bash
git clone https://github.com/Almerek999/sanau-ai.git
cd sanau-ai

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения:
Скопируйте пример конфигурации:
```bash
cp .env.example .env
```
В файле `.env` укажите ваш Telegram Bot Token и OpenAI / Gemini API Key:
```env
TELEGRAM_BOT_TOKEN=your_token_from_botfather
OPENAI_API_KEY=sk-proj-...
```

### 3. Запуск одной командой:
```bash
./run.sh
```
Скрипт автоматически:
- Запустит сервер FastAPI на `http://localhost:8000`;
- Поднимет безопасный Cloudflare HTTPS Tunnel для Telegram Mini App;
- Привяжет кнопку «📱 Открыть Mini App» в меню Telegram-бота;
- Запустит воркер Telegram-бота.
